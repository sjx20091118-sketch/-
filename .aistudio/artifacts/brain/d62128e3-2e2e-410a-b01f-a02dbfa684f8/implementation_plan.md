# 全景时光年份穿透过滤与人物分组空态极简重构计划

## 概述与核心目标
本项目致力于解决「全景时光」全局年份选择器在跨模块（拾光轴、拾忆篇、拾物阁）数据穿透过滤不彻底的问题，确保选定特定年份（如2035年或未来/历史指定年份）时全模块精准联动；当该年份无数据时展示清雅空态与快捷添加瞬间入口；同时重构好友分组无成员时的极简空态，替换繁复插图为底部导航原生精炼图标并精简引导文字；全面审查代码及各功能模块。

---

## 用户确认决策与设计方案

> [!IMPORTANT]
> 针对最新需求与澄清答复，已确立如下实施准则：

- **全景时光年份全局穿透过滤**：顶部年份选择器选定年份后，全局贯穿「拾光轴（时光线）」、「拾忆篇（手账/故事）」、「拾物阁（老物件/收藏）」及「全景时光汇总」，彻底杜绝跨年份数据混杂。
- **无记录年份优雅空态**：当所选年份（如2035年）无记忆档案时，展示与整体东方 iOS 玻璃质感一致的清雅提示，并提供「＋ 记录该年第一个瞬间」快捷录入通道。
- **人物列表分组空态重构**：移除多余繁杂插画，直接复用底部导航栏同源精炼图标（Users / Bookmark），删除下方冗余的“可点击好友卡片编辑资料...”冗长文字说明。
- **全站代码健壮性审查**：全面排查 TypeScript 语法、TTS 语音合成容错、ZIP 备份解压逻辑、媒体流及各弹窗边界状态，保障稳定运行。

## 1. 详细体验与视觉设计

### 1.1 全景时光与年份联动穿透
- **全局年份响应机制**：
  - 选定全部年份（`selectedYear === null` 或 `'all'`）时展示完整生命周期数据。
  - 选定具体年份（如 `2035`、`2026`、`2024`）时，对时光轴、相册篇章、物品阁进行严格的日期年匹配（`new Date(item.date).getFullYear() === selectedYear` 或正则匹配提取年份）。
  - 统计数据（如“共收录 N 个瞬间”）实时同步为当前年份过滤后的精确计数。
- **年份空态呈现**：
  - 居中展示半透明柔光圆环容器 + 极简日历/时光沙漏线性图标。
  - 标题：`「{selectedYear} 年暂无档案记录」`。
  - 副标题：`岁序常易，此年暂未留存瞬间`。
  - 快捷按钮：`轻触添加该年首个记忆`，点击即调起记忆录入面板并自动预填该年份日期。

### 1.2 人物分类列表与空态极简优化
- **精炼图标规范**：采用与底部导航栏相同的极简线性/双色图标（微羽白/金杏质感），彻底告别大面积插图。
- **纯净版面**：仅保留“该分组暂无人物”单行清雅文本，完全移除下方冗余提示段落，视觉轻盈克制。
